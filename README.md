# PDF – Matemática Financeira

Aplicativo web progressivo (PWA). Hospedagem estática sem etapa de build.

## Publicação
Suba o conteúdo desta pasta para um repositório exclusivo no GitHub. No Netlify: Add new project > Import an existing project > GitHub > selecione o repositório. Configure publish directory como `.` e deixe Build command vazio.

## Instalação
Android: abra o endereço HTTPS no Chrome e escolha Instalar app ou Adicionar à tela inicial. iPhone: abra no Safari, Compartilhar > Adicionar à Tela de Início.

O cache offline é criado após a primeira visita conectada. O progresso salvo no dispositivo não sincroniza entre aparelhos.
